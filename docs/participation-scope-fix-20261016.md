# 推广内容与论坛红包领取条件

代理试用、外部机器人和邀请码推广可能同时附带独立的论坛红包。原判断只有正文和活动类型，容易把领取外部产品权益的步骤当作领烧饼的前提，导致正常回帖红包停在人工复核。

现在把经过身份、活动控件和表单检查的官方报名说明作为独立上下文，排除正文伪造说明、参与者名单和认证字段。初步条件判断不确定时，分别判断额外操作是否约束本论坛红包、这些步骤是否只属于另一个推广权益。只有前者不高于0.15且后者不低于0.85时才解除这项条件疑虑；明确的论坛条件仍拦截，其余不确定情况继续使用原Choice门槛。输入检查、字数验证、回复检查、暂停、费用预算及提交防重保持。

策略版本4允许版本2/3中零费用、从未尝试提交的红包附加条件记录重新走一次随机等待和完整检查。记录若包含提交、传输或HTTP证据，或已确认、结果未明，均不重试；新版再次转人工后不反复重排。过期和已经参与会在重新读取页面时停止，不生成或提交回复。旧AI待复核不在此范围。

回归覆盖独立产品试用、机器人词元推广，真正绑定领饼的注册/关注要求及付费奖品，模糊条件、检查接口失败、输入注入、不可执行字数、完整提交链条与旧记录重排边界。验证时使用合成数据和断网Mock；业务验收另外依据自然任务及官方账号参与标记，不能把查询确认全部称作程序受理。
